# Microsoft Health Live
Painel independente de avisos públicos. Node.js 22+. Execute npm install e npm start. Consulta RSS/Atom no servidor a cada 30 segundos, sem credenciais Microsoft. Fonte: https://status.cloud.microsoft/api/feed/mac . Endpoint público de dados: /api/status . Não equivale a um inventário de status por serviço. Feed indisponível aparece como sem confirmação. Não há histórico de uptime inventado. Títulos e avisos são traduzidos para pt-BR no servidor via MyMemory (cache por trecho — só retraduz o que mudou; em caso de falha exibe o texto original em inglês).
